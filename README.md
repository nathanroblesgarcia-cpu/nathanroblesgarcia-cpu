### Featured projects

**[recall-rag](https://github.com/nathanroblesgarcia-cpu/recall-rag)**: a local,
private RAG app over your own notes, with an automated eval suite. Hybrid search
(vector plus keyword), a local or cloud answer model, a tool-calling agent, and a
golden-set eval that scores both retrieval and answer quality (24/24 on the demo set).
Built with Flask, SQLite, fastembed, and Ollama, and written to be read, not just run.

**[earshot](https://github.com/nathanroblesgarcia-cpu/earshot)**: a local meeting
note-taker for Windows that records calls without a bot joining. Offline transcription
with faster-whisper (including English/Tagalog code-switching), notes and dated action
items from a local LLM, and a signal-level speaker-bleed detector with its own eval
(16/16 bleed caught, 0/32 real lines dropped). Also has call detection, 1:1 prep sheets,
an MCP server, and a 33-test suite.
